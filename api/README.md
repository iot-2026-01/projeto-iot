# Smart Load Balancing API

Backend API for the Smart Load Balancing System IoT project, built with Node.js 24.x, Express, and TypeScript.

## Features

- RESTful API following OOP patterns
- Well-structured directory organization
- TypeScript type safety
- Modular design with controllers and models
- Express.js framework
- Health check endpoint
- Error handling middleware
- Test suite with Jest
